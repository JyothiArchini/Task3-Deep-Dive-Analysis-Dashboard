# Deep-Dive Analysis & Interactive Dashboarding

## Project Overview

This project presents a deep-dive analysis of the Superstore dataset using Microsoft Power BI. The dashboard provides interactive visualizations, key performance indicators (KPIs), customer segmentation analysis, and regional performance insights to support business decision-making.

## Objectives

* Analyze business performance using KPIs.
* Perform customer segmentation analysis.
* Analyze regional sales and profit.
* Build an interactive Power BI dashboard.

## Dataset

* Dataset: Superstore Sales Dataset
* Records: Approximately 5000 orders
* Tool Used: Microsoft Power BI Desktop

## KPIs

* Total Sales
* Total Profit
* Total Orders
* Average Order Value (AOV)
* Profit Margin

## Dashboard Pages

### Executive Overview

* KPI Cards
* Sales by Category
* Profit by Category
* Monthly Sales Trend
* Interactive Filters

### Customer Segmentation

* High, Medium, and Low Value Customers
* Customer Distribution
* Sales by Segment
* Top Customers

### Regional Performance

* Sales by Region
* Profit by Region
* Top 10 States by Sales
* Sales by Ship Mode
  
Note: Due to Power BI Service publishing limitations, the interactive dashboard is provided as a .pbix file. It can be opened using Microsoft Power BI Desktop.

## Key Insights

* Technology category generated the highest sales.
* West region achieved the highest revenue and profit.
* Standard Class shipping accounted for the largest share of sales.
* A small group of high-value customers contributed significantly to total revenue.
